
# NLP Analysis Studio

A dual-model NLP application built with Streamlit and Hugging Face Transformers.

## Models

### 1. BERT Sentiment Classifier
Model: ullahhafeez321/bert-sentiment-classifier

Architecture: Encoder-only

Task: Sentiment classification.

### 2. Qwen NER Decoder
Model: ullahhafeez321/Qwen-NER-Decoder

Architecture: Decoder-only

Task: Named Entity Recognition.

## Features

- Independent sentiment classification.
- Named entity extraction.
- Combined analysis dashboard.
- Confidence scores.
- Entity types and structured output.
- Hugging Face integration.
- Streamlit deployment.

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment

Deploy using Streamlit Community Cloud:

https://share.streamlit.io/

Connect your GitHub repository and select app.py.
